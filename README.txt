# Romantic Date Invitation Website

Files:
- index.html
- style.css
- script.js
- assets/music.mp3 (add your own song)
- assets/video.mp4 (add your own video)

Open index.html in a browser.

To change the song title, edit:
`<strong id="songTitle">Your Song Title</strong>`

To change the media, replace the files inside `assets/`.

Note: modern browsers often block autoplay audio until the visitor interacts with the page. The site attempts autoplay and starts music on the first interaction if blocked.
